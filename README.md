## About

Backend and AI engineer building reliable **Python services, LLM applications, data pipelines, and developer tooling**. I enjoy turning ambiguous problems into focused, tested changes—from API and workflow design to debugging mature open-source codebases.

- **AI systems:** LLM applications, agents, RAG, evaluation, and MCP integrations
- **Backend:** Python, FastAPI, Django, REST APIs, authentication, and background jobs
- **Data and delivery:** PostgreSQL, Redis, Docker, GitHub Actions, testing, and CI/CD
- **Current focus:** useful open-source contributions across AI infrastructure and Python tooling
